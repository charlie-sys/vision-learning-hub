1. 如何使用新增选项

在论文目录的“分类”下拉框选择“视觉幻觉 · 图像/视频理解”，即可查看全部79篇；随后用“视觉幻觉研究方向”进一步筛选。中英文题名、作者、关键词、要点和摘要均可搜索。筛选条件保存在网址中，可以复制给同学或收藏。

卡片中的“原表 #”对应Excel第一列序号；网站编号31–109接在原有30篇基础论文之后。新论文没有在原表中标注阅读优先级，因此保留为“未分级”，不另行赋予必读/进阶等级。

每张卡片提供原文PDF、原始题录页面和翻译阅读入口；原表提供代码/项目链接时，也会显示相应按钮。展开“中英文摘要与表格信息”，可查看完整作者、摘要、关键词、发表载体、CCF、分区、影响因子及原表说明。

3. 建议阅读顺序

先从“综述与理论”建立概念，再读“幻觉机理与检测”，随后选择“图像幻觉基准与评测”或“视频幻觉基准与评测”，明确自己关注的错误类型和评价方式。方法阅读可沿偏好对齐、解码干预、注意力/表征干预三条路径展开，最后进入视频理解增强以及音视频、医学、OCR等扩展。

这是一条使用目录的建议路线。每篇的具体结论和适用条件仍应回到全文核对；目录中的中文要点及译文按用户原表收录，正式引用使用英文原题。

4. 原表信息与本地PDF核对

导入时按arXiv ID连接表格、用户提供的文件清单和本地PDF，核对了79个题名映射，并确认79份PDF均可打开和提取首页文字；78份首页直接识别到arXiv编号，另外1份通过题名及文件清单匹配。核对记录见导入报告。

网站的PDF按钮连接公开原文，包含可获取的固定版本链接；下载脚本也可按网站编号获取论文。论文遵循各自许可，项目提供题录、译写、链接和下载工具。

发表载体、CCF推荐等级、中科院/JCR分区、影响因子及备注保留原表记录和说明；此次工作核对了题录与文件对应关系，未逐篇重新确认最新录用状态或评级。原表中“未标注/不适用”等值照录，不作为缺失值填成0。

5. 维护与更新

原表21个字段保存在 data/hallucination_source.csv，补充版本信息保存在 data/hallucination_source_metadata.json。运行 python scripts/import_hallucination.py 可重新合并专题；原有基础论文编号保留。再运行 python scripts/build.py、python scripts/validate.py 和 python scripts/check_hallucination.py，提交生成网页即可更新。
