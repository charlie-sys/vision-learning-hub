# 英文论文翻译阅读指南

在论文目录点击任一论文的 **“翻译阅读”**，会弹出该论文的翻译助手，显示原始 PDF、复制链接按钮和在线工具入口。

## 1. 边读边看中英对照：沉浸式翻译扩展

适合在自己的 Chrome、Edge、Firefox 或 Safari 浏览器中持续阅读论文。

1. 从[沉浸式翻译官网](https://immersivetranslate.com/zh-Hans/)选择自己的浏览器，安装官方扩展。
2. 在本网站的翻译助手中点击 **“打开本篇 PDF”**。
3. 点击浏览器扩展图标，选择 **“翻译 PDF”**，在工具中选择简体中文及翻译服务。
4. 在其 PDF 阅读器中查看双语内容。段落/页面的处理速度取决于文档和所选翻译服务。

普通 PDF 翻译通常处理可提取文字的 PDF；扫描件和复杂排版应按工具指引选择 OCR 或其他文档翻译方式。参见[官方 PDF 使用说明](https://immersivetranslate.com/zh-Hans/docs/usage/#pdf-文件翻译)。

浏览器扩展需要安装在实际阅读论文的浏览器中。应用内嵌浏览器如果无法安装扩展，请选择下面的在线文档翻译方式，或在外部浏览器打开论文。

## 2. 在线生成双语文档：BabelDOC

1. 在翻译助手中打开本篇 PDF，并将 PDF 保存到本地。
2. 打开 [BabelDOC 在线工具](https://app.immersivetranslate.com/babel-doc/)。
3. 在服务页面上传 PDF，按其提示选择语言、模型和开始翻译。
4. 等待任务完成，再查看或下载双语文档。

这种方式需要等待解析和翻译完成。账号、可用模型、文档大小限制和额度以第三方服务当前页面为准。请在服务页面自行决定是否上传和开始任务。[官方文档翻译帮助](https://immersivetranslate.com/zh-Hans/document/help/)

## 3. 当前入口提供哪些功能

| 操作 | 本网站提供的行为 |
|---|---|
| 点击“翻译阅读” | 打开当前论文的翻译助手弹窗 |
| 打开本篇 PDF | 在新标签页打开公开原文 |
| 复制论文链接 | 便于粘贴到支持链接导入的阅读工具 |
| 打开在线翻译器 | 在新标签页进入第三方在线服务 |
| 完全在本站内自动翻译 | 当前未提供；需要独立的 PDF 解析与翻译后端 |

网页无法在已跳转到的出版商网站或浏览器内置 PDF 页面上直接注入本网站的翻译按钮。现有入口将论文和工具集中在一起，扩展或在线服务负责实际翻译。

## 4. 阅读时怎样使用译文

中文译文适合快速理解；推导、数值、实验结论和术语应与英文原文对照。遇到 `score`、`latent`、`token`、`guidance` 等术语，结合上下文确认译法；公式符号按原论文核对。
